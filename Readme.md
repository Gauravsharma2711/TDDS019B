# 🎓 TyBSc Data Science Practicals Repository

Welcome to my academic repository! This repository contains a comprehensive collection of practical assignments, lab work, and projects completed during my **Third Year of B.Sc. in Data Science**.

The repository is systematically organized into four core subjects, covering the end-to-end pipeline of modern data science—from building APIs and visualizing data to implementing Machine Learning models and Natural Language Processing techniques.

---

## 📂 Repository Structure

This repository is divided into four main directories, each representing a key subject of the curriculum:

| 📁 Folder Name | 📚 Subject | 📝 Description |
| :--- | :--- | :--- |
| `application-programming-interface` | **Application Programming Interface** | Practical work focusing on creating, consuming, and testing RESTful APIs, web scraping, and server-side data handling. |
| `data-visualization` | **Data Visualization** | Notebooks and scripts demonstrating effective data storytelling using libraries like Matplotlib, Seaborn, and Plotly. |
| `machine-learning` | **Machine Learning** | Implementations of various ML algorithms (Supervised & Unsupervised), model training, evaluation, and hyperparameter tuning. |
| `natural-language-processing` | **Natural Language Processing** | Text preprocessing, sentiment analysis, tokenization, and language modeling using NLTK, spaCy, and Hugging Face. |

> 📌 **Note:** Each folder contains its own set of practicals, datasets (where applicable), and Jupyter Notebooks/Python scripts.

---

## 🛠️ Tech Stack & Tools

The practicals within this repository utilize the following tools, libraries, and frameworks:

* **Languages:** Python, SQL
* **Data Manipulation:** Pandas, NumPy
* **Data Visualization:** Matplotlib, Seaborn, Plotly
* **Machine Learning:** Scikit-Learn, XGBoost
* **NLP:** NLTK, spaCy, TextBlob
* **API / Web Frameworks:** Flask, FastAPI, Requests
* **Environments:** Jupyter Notebook, VS Code
